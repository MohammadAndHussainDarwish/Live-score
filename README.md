# Live-score — مواعيد الملاعب

موقع عربي متجاوب لعرض مباريات كرة القدم ونتائجها حسب التاريخ والبطولة، باستخدام واجهة [Free Football Live Scores](https://worldcup26.ir/football-api).

## المتطلبات

- Node.js 18 أو أحدث
- اتصال بالإنترنت للوصول إلى API. لا يلزم مفتاح API.

## التشغيل على Windows

شغّل الخادم:

```powershell
node server.js
```

افتح بعدها الرابط الذي يظهر في نافذة التشغيل. يحاول الخادم استخدام المنفذ 5000، وينتقل تلقائيًا إلى منفذ تالٍ إذا كان مشغولاً. يجلب الخادم قائمة البطولات المتاحة ثم مباريات التاريخ المحدد من واجهة worldcup26.ir، دون الحاجة إلى مفتاح API.

يمكن تغيير المنفذ باستخدام متغير البيئة `PORT`. وتخضع التغطية وتحديث المباريات لتوفر البيانات في خدمة worldcup26.ir.
